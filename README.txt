============================
  MyTool 批量生图工具 快速上手
============================

【这是什么】
通过即梦 AI 做「图生图」批量生成电商商品图的本地工具。
- 即梦负责出图（消耗你即梦账号的积分）
- DeepSeek 负责把你的商品描述写成生图提示词
即梦账号要你自己登录；DeepSeek 需要你自己填 API Key（公司已提供一个
key，写在《DeepSeek_API_Key_配置指南.pdf》里，复制填入即可）。


【首次使用 · 4 步走】

第 1 步：装 Python 依赖（只需一次）
  - 确认电脑已装 Python 3.10+（命令行跑 python --version 能看到版本号）
  - 双击「安装依赖.bat」，或命令行执行：pip install -r requirements.txt

第 2 步：登录即梦账号（生图扣这个账号的积分）
  - 双击「登录即梦账号.bat」
  - 按终端提示，浏览器打开验证网址，输入验证码完成授权
  - 详见《即梦账号登录与使用指南.pdf》

第 3 步：配置 DeepSeek（让 AI 帮你写提示词）
  - 浏览器登录工具后（见第 4 步），点右上角「设置」
  - 把《DeepSeek_API_Key_配置指南.pdf》里提供的公司 Key 复制填入，保存
  - 详见该 PDF 指南

第 4 步：启动工具并设本机密码
  - 双击「启动.bat」
  - 命令行显示「访问 http://127.0.0.1:9527/」即成功
  - 浏览器打开该网址，首次会让你设一个 ≥6 位本机密码
    （这是保护工具入口的密码，和即梦/DeepSeek 无关）


【日常使用 · 2 步】

1. 双击「启动.bat」 → 浏览器打开 http://127.0.0.1:9527/
2. 左侧拖入商品图 → 中间写商品描述 → AI 生成提示词 → 开始生图
   （生成的图在 output 目录，也可在网页右侧查看）


【目录说明】

  bin\dreamina.exe              即梦官方工具（自动调用，一般别动）
  登录即梦账号.bat              登录即梦（首次 & 失效时用）
  查积分.bat                    查即梦账号剩余积分
  启动.bat                      启动 MyTool 服务
  config.json                    配置文件（含 DeepSeek key，勿外传）
  app.py / auth.py 等           程序源码
  即梦账号登录与使用指南.pdf     即梦账号详细操作手册
  DeepSeek_API_Key_配置指南.pdf  DeepSeek 配置详细手册


【常见问题 · 快速定位】

- 生图报「未登录」        → 重新双击「登录即梦账号.bat」
- 生图报「积分不足」      → 双击「查积分.bat」确认，不足去即梦官网充值
- 提示词很像/没创意       → DeepSeek key 没填好，走的是本地兜底，看 DeepSeek 指南
- 端口 9527 被占          → 关掉其他占用程序，或改 app.py 里的 port
- python 不是命令         → 先装 Python（https://www.python.org/downloads）


【重要提醒】

- DeepSeek 指南里写有公司提供的 API Key（公司付费，暂时方案），请勿把该指南/目录分享/上传到公开地方
- .dreamina_cli 登录态在你用户目录，换电脑要重新登录即梦
- 两份 PDF 指南是完整操作手册，遇到问题先翻对应指南的「常见问题」章节
